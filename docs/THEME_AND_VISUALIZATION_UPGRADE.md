# 🎨 Ops Assistant - 主题切换 & 数据可视化升级

## 新增功能

### 1️⃣ 主题切换（暗色/亮色）

**功能特性：**
- ✅ 一键切换暗色和亮色主题
- ✅ 自动保存用户偏好到 localStorage
- ✅ 跟随系统主题偏好（首次访问时）
- ✅ 流畅的主题切换动画

**使用方法：**
- 点击顶部导航栏右侧的太阳/月亮图标
- 暗色模式：深色背景，青色主题
- 亮色模式：浅色背景，柔和配色

**技术实现：**
```typescript
// 使用 composable 管理主题
import { useTheme } from '@/composables/useTheme'

const { theme, toggleTheme } = useTheme()
```

**文件修改：**
- `src/composables/useTheme.ts` [新增] - 主题管理 composable
- `src/App.vue` [修改] - 添加主题切换按钮和亮色主题 CSS 变量

### 2️⃣ 数据可视化

#### 置信度环形图 + 匹配度条形图

**功能特性：**
- ✅ 置信度环形进度条（SVG 动画）
- ✅ Top 5 知识匹配度条形图
- ✅ 实时渐变色反馈（绿/黄/红）
- ✅ 流光动画效果

**组件：**
`ConfidenceChart.vue` - 综合展示置信度和匹配度

**展示内容：**
- 左侧：置信度环形图（百分比）
- 右侧：前 5 条匹配知识的匹配度条形图

**颜色映射：**
- 🟢 高置信度/匹配度 (≥80%)：绿色
- 🟡 中等 (60-80%)：黄色
- 🔴 低 (<60%)：红色

#### 关键词标签云

**功能特性：**
- ✅ 动态大小和颜色
- ✅ 渐入动画（错峰显示）
- ✅ 悬停放大效果
- ✅ 多彩边框设计

**组件：**
`KeywordsCloud.vue` - 关键词可视化展示

**视觉效果：**
- 不同关键词使用不同颜色边框
- 字体大小有变化，营造云状效果
- 悬停时轻微放大

## 🛠️ 技术细节

### 主题系统架构
```typescript
useTheme()
  ├─ theme: Ref<'dark' | 'light'>
  ├─ toggleTheme()
  ├─ setTheme(theme)
  └─ initTheme()

CSS Variables:
  [data-theme="dark"]  // 暗色主题变量
  [data-theme="light"] // 亮色主题变量
```

### 可视化技术栈
- **SVG 动画**：环形进度条
- **CSS 渐变**：条形图颜色
- **CSS 动画**：关键词渐入、流光效果
